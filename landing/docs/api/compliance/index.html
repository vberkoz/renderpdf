Enterprise & compliance

Factur-X & PDF/A archival compliance

POST/render

Comply with European mandatory e-invoicing laws (such as French B2B 2026 mandates and German ZUGFeRD) and ISO 19005 long-term preservation standards. Configuring options.compliance produces certified hybrid electronic invoices and archival documents.

Compliance profiles

profilestringrequired

Archival profile or hybrid e-invoicing standard:

  • factur-x: Hybrid Franco-German e-invoice based on PDF/A-3b with embedded Factur-X XML.
  • zugferd: German ZUGFeRD 2.x e-invoice profile (PDF/A-3b).
  • pdfa-1b: ISO 19005-1 Level B archival profile.
  • pdfa-2b: ISO 19005-2 Level B archival profile.
  • pdfa-3b: ISO 19005-3 Level B archival profile (allows embedded files).

invoiceXmlstringrequired for factur-x / zugferd

Structured XML invoice payload adhering to the UN/CEFACT CII syntax or UBL. Can be passed as a raw XML string or a base64-encoded string.

invoiceProfilestringoptional

Conformance profile level: EN 16931 (default; standard EU mandate), MINIMUM, BASIC WL, BASIC, or EXTENDED.

xmlFilenamestringoptional

Name assigned to the embedded attachment stream. Defaults to factur-x.xml for Factur-X or zugferd-invoice.xml for ZUGFeRD.

documentTypestringoptional

XMP document descriptor. Defaults to "INVOICE".

versionstringoptional

Schema version descriptor for the XMP metadata extension. Defaults to "1.0".

Automated pipeline injection

When a compliance profile is enabled, RenderPDF automatically performs the required low-level PDF manipulations:

  • Color management: Injects standard sRGB IEC61966-2.1 OutputIntents dictionary (GTS_PDFA1 or GTS_PDFA3).
  • Embedded file tree: Embeds the structured XML invoice into the PDF /EmbeddedFiles catalog, links it in /AF with relationship /Data, and sets MIME subtype /text/xml.
  • Adobe XMP extension schema: Stamped with official pdfaid:part, pdfaid:conformance, and Factur-X schema namespace (urn:factur-x:pdfa:CrossIndustryDocument:invoice:1p0#).

PDF/A encryption restriction: Under the ISO 19005 specification, PDF/A documents strictly forbid password encryption. Submitting options.compliance together with password or ownerPassword will return HTTP 422 Unprocessable Entity.

Request example

cURL · Factur-X EN 16931 hybrid e-invoice
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version": "1",
    "source": {
      "type": "html",
      "content": "<main><h1>Invoice #INV-2026-001</h1><p>Billed to: Acme Corp</p><p>Amount: €1,200.00</p></main>"
    },
    "options": {
      "format": "A4",
      "margin": "18mm",
      "compliance": {
        "profile": "factur-x",
        "invoiceProfile": "EN 16931",
        "invoiceXml": "<rsm:CrossIndustryInvoice xmlns:rsm=\"urn:un:unece:uncefact:data:standard:CrossIndustryInvoice:100\">...</rsm:CrossIndustryInvoice>"
      }
    }
  }'
