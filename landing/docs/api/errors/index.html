Delivery and errors

Errors

Error responses are JSON and always include a human-readable error message plus a stable code for programmatic handling. When a request reaches the API service, it also includes requestId; retain it when contacting support.

422 / application/json
{
  "error": "An image failed to load while rendering the page",
  "code": "image_loading_failed",
  "requestId": "7db7..."
}
API errors
StatusCodeMeaning
400invalid_requestInvalid JSON, missing HTML, an empty document, or an invalid render URL.
400document_request_invalidMalformed document JSON, wrong field types, trailing JSON, or unknown fields.
401authentication_requiredAuthentication is required for the requested route.
403—Missing, invalid, or inactive API key; this response is produced by API Gateway before the request reaches the service.
404not_foundThe requested endpoint is unavailable or does not exist in this deployment mode.
413payload_too_largeTrial HTML exceeds the 1 MB limit.
413document_*_too_largeDocument request, HTML, CSS, data, or compiled renderer input exceeds its documented limit.
422document_binding_*A document binding is missing, unused, or malformed.
422document_format_invalid / document_margin_invalidPaper format or margin is unsupported.
422document_*_unsafe / document_asset_disallowed / document_page_settings_disallowedDocument HTML, CSS, URL, asset, or page settings violate the security policy.
422image_loading_failedAn image resource could not be loaded while rendering.
422css_parsing_errorChromium reported a CSS parsing error.
422javascript_exceptionThe page raised an uncaught JavaScript exception.
422navigation_failedChromium could not navigate to the requested page.
429rate_limitedDaily anonymous trial or monthly account limit reached.
500storage_failedThe rendered PDF could not be stored; retry the request.
500rendering_failedAn unexpected rendering failure occurred.
503service_unavailableA dependent service is temporarily unavailable.
503api_keys_unavailableAPI-key management is temporarily unavailable.
504navigation_timeoutThe page did not finish navigating before the render deadline.
504chromium_timeoutChromium timed out while starting or generating the PDF.

Handling failures

400 / 413 / 422Correct the request or document before trying again. Do not retry unchanged input.
403Check that the API key is present, active, and sent as Authorization: Bearer <key>.
429 / 503 / 504Wait and retry with exponential backoff. Preserve the original input so the retry is identical.
500Retry once for a transient failure; if it persists, retain the response and request details for support.

The renderer may log further diagnostic detail, but API responses deliberately omit page content, URLs, and browser internals.
