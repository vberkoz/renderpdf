Reusable assets and batch work

Store HTML templates

CRUD/templates

Save reusable HTML once, then render it with only variable data. Templates belong to the API-key owner; another customer receives 404 for the same ID.

POST /templatesAPI key

Create with name, type, html, and optional default variables. Default data must match the template placeholders. Types are invoice, contract, certificate, receipt, or custom. Returns 201.

GET /templatesAPI key

Lists your saved templates plus bundled starter schemas.

GET /templates/{id}API key

Reads one owned template.

PUT /templates/{id}API key

Replaces name, type, HTML, and default variables; version increments.

DELETE /templates/{id}API key

Deletes an owned template and returns 204.

cURL
curl -X POST https://renderpdf.vberkoz.com/api/v1/templates \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"name":"Invoice","type":"invoice","html":"<!doctype html><html><body><h1>Invoice {{invoice.number}}</h1><p>{{customer.name}}</p></body></html>","variables":{"invoice":{"number":"INV-1042"},"customer":{"name":"Ada & Sons"}}}'

Starter variable schemas

  • Invoice: invoice.number, invoice.issueDate, invoice.dueDate, invoice.description, invoice.total, customer.name, customer.address.
  • Contract: contract.title, contract.date, contract.scope, contract.startDate, contract.endDate, contract.paymentTerms, party.one.name, party.two.name.
  • Certificate: certificate.title, certificate.achievement, certificate.date, certificate.number, recipient.name.
  • Receipt: merchant.name, merchant.address, receipt.number, receipt.date, receipt.description, receipt.amount, receipt.total, customer.name.
i

Limits: 100 templates per owner, 1 MiB of HTML, and 256 KiB of default variables per template. Values are HTML escaped; raw HTML variable interpolation is unsupported.
