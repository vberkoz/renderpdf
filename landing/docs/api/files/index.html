Reusable assets and batch work

Files and private downloads

GET/files

Uploaded packages, rendered PDFs, and batch ZIPs remain private. File routes authorize every record by API-key owner and issue short-lived signed URLs instead of public object links.

POST /files/uploadAPI key

Issue a 15-minute ZIP upload URL. Packages are limited to 25 MiB compressed, 50 MiB extracted, and 500 files.

GET /files/{id}/downloadAPI key

Issue a 15-minute signed download URL for an owned file.

DELETE /files/{id}API key

Delete owned metadata and its private object. PDFs retain for up to 30 days; uploads retain for one day.
