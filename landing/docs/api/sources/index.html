Saved sources

CRUD/sources

Save reusable HTML/CSS JSON or Markdown definitions privately, then render them later with per-request data. Source definitions are never returned in list or metadata responses.

POST /sourcesAPI key

Create { name, definition }, where definition is a version-1 HTML or Markdown render request without webhook settings.

GET /sourcesAPI key

List owned source metadata. Use GET, PUT, or DELETE /sources/{id} for one source.

{
  "version": "1",
  "source": { "type": "stored", "id": "src_..." },
  "data": { "customer": { "name": "Ada" } }
}

Render this payload through POST /render. Sources are limited to 100 definitions and 25 MiB total per account.
