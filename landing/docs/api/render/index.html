Render inputs

Render

POST/render

The canonical authenticated endpoint selects HTML, Markdown, saved templates or sources, public URLs, or uploaded packages with source.type, then stores the PDF privately and returns a signed download URL.

Request body

version string required

Contract version. Must be "1".

source object required

A versioned source object. Use { "type": "html", "content": "..." } for controlled HTML/CSS documents, or markdown, template, url, upload, or stored for the matching source mode.

css string optional

Custom CSS applied to the HTML or Markdown content (up to 128 KiB). Supports Flexbox, CSS Grid, custom fonts, and standard print styling.

data object optional

Key-value mappings for dynamic {{path.to.value}} bindings. Inserted values are automatically HTML-escaped.

options object optional

Comprehensive rendering, formatting, watermarking, smart triggers, and security settings (detailed below).

label string optional

Tracking label (up to 120 characters) for identification in logs and activity dashboards.

webhookUrl string optional

Public HTTPS URL for event-driven pdf.completed notification.

Render options (`options`)

formatstring

Paper format: A4 (default), Letter, or Legal.

marginstring

Page margin in mm (0–50mm) or in (0–2in). Default: 18mm.

pageNumbersobject

Vector page numbers stamped across pages: format (e.g. "Page {page} of {total}"), position (bottom-center|bottom-right|bottom-left|top-center|top-right|top-left), startPage, startNumber, excludeCover (boolean), fontSize, color.

watermarkobject

Vector watermark stamped via pdfcpu:

  • text: Watermark text (e.g. "CONFIDENTIAL").
  • diagonal: Stamped corner-to-corner along page diagonal (default: true).
  • rotation: Custom angle from -360 to 360 degrees. Overrides diagonal.
  • opacity: Float from 0.0 (transparent) to 1.0 (opaque). Default: 0.15.
  • color: 3 RGB floats (e.g. "0.5 0.5 0.5") or hex code (e.g. "#dc2626").
  • fontSize: Font size in points (1 to 144, default: 54).
  • font: Standard PDF base font: Helvetica (default), Times-Roman, or Courier.
  • position: center (default), top-center, top-left, top-right, bottom-center, bottom-left, bottom-right.
  • pages: Page range selection: "all" (default), "odd", "even", "1", or "2-".

waitForobject

Smart wait-for triggers evaluated before capturing the PDF snapshot:

  • selector: CSS query selector to await until rendered in DOM (e.g. "#chart svg").
  • function: Polled JavaScript expression returning true when client-side rendering is ready (e.g. "() => window.RENDER_READY === true"). Disallowed in document JSON mode.
  • networkIdle: Wait until in-flight network activity drops to 0 or 2: "networkidle0" or "networkidle2".
  • timeoutMs: Maximum wait timeout in milliseconds (0 to 20,000 ms, default: 5000).
  • fonts: Wait for document.fonts.ready before printing (default: true).

password, ownerPassword, permissions

AES-256 PDF encryption. See Security & Passwords.

redaction

AST-level PII sanitization. See PII Redaction.

signing

X.509 or AWS KMS digital signatures. See Digital Signatures.

compliance

Factur-X and PDF/A archival compliance. See Compliance & Factur-X.

Built-in print styling & pagination helpers

RenderPDF automatically optimizes HTML for print layout before invoking Chromium:

  • Exact color fidelity: Injects print-color-adjust: exact so background colors, borders, and charts print exactly as styled.
  • Break avoidance classes: Elements with classes .avoid-break, [data-avoid-break], .signature, .signature-block, .totals-area, .grand-total, and figure automatically receive break-inside: avoid to prevent awkward mid-element page splits.
  • Clean table pagination: Table headers (<thead>) automatically repeat across pages with display: table-header-group, while <tfoot> elements are normalized to prevent footer repetition across every single page.

Request example

cURL · HTML render with watermark and wait-for 
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version": "1",
    "source": {
      "type": "html",
      "content": "<main><h1>Quarterly Report #1042</h1><div id=\"chart\">Loading...</div></main>"
    },
    "options": {
      "format": "A4",
      "margin": "15mm",
      "watermark": {
        "text": "DRAFT",
        "diagonal": true,
        "opacity": 0.12,
        "color": "#ef4444"
      },
      "waitFor": {
        "selector": "#chart svg",
        "networkIdle": "networkidle0",
        "timeoutMs": 4000
      }
    }
  }'
