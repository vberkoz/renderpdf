Render a stored template

POST/render

Resolve a customer-owned template with nested variables, dynamic vector barcodes, and custom layout settings, then receive the normal signed PDF response.

templateIdstringrequired

The ID returned by POST /templates.

variablesobjectrequired

Nested values matching every {{path.to.value}} placeholder. Missing or additional leaves return 422.

cURL
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"version":"1","source":{"type":"template","templateId":"TEMPLATE_ID","variables":{"invoice":{"number":"INV-1042"},"customer":{"name":"Ada & Sons"}}}}'

HTML source workflow

  1. Move stable HTML into POST /templates.
  2. Replace dynamic text with {{path.to.value}}.
  3. Save the returned template ID in application configuration.
  4. Send templateId and variables instead of full HTML payloads.
  5. Handle 422 by adding missing values or removing extras.

Dynamic vector barcodes & QR codes

Templates can directly embed resolution-independent vector barcodes and QR codes rendered as inline SVGs server-side. Zero client-side JavaScript or canvas libraries are required.

Handlebars-style template helpers

Bind data variables or static literals to QR and barcode helpers:

  • {{qrcode url}} or {{qrcode invoice.paymentUrl size="140px" level="H"}}
  • {{barcode '128' trackingId width="200px" height="50px" text=true}}
  • {{barcode 'code39' orderNumber}} or {{barcode 'datamatrix' secretKey}}

HTML tags & custom attributes

You can also write custom semantic tags or HTML data attributes:

  • <qrcode value="https://example.com" size="140" level="M|L|Q|H" color="#000" background="#fff" />
  • <barcode type="code128|code39|ean13|ean8|2of5|datamatrix|pdf417|qr" value="INV-2026" width="220" height="60" text="true|false" />
  • <div data-qrcode="https://example.com" data-qr-size="120px"></div>
  • <div data-barcode="INV-2026" data-barcode-type="code128"></div>

Supported symbologies

code128 (or 128)

Standard high-density alphanumeric shipping, logistics, and invoice barcode.

code39 (or 39)

Widely used legacy alphanumeric barcode for identification and military applications.

ean13 / ean8

International Article Number (European Article Number) standard for retail items.

2of5

Interleaved 2 of 5 numeric barcode used in distribution and warehousing.

datamatrix

Two-dimensional matrix barcode ideal for compact labeling and electronics packaging.

pdf417

High-capacity stacked linear 2D barcode used for airline boarding passes and transport tickets.

qr (or qrcode)

Quick Response matrix barcode with configurable Reed-Solomon error correction (L 7%, M 15%, Q 25%, H 30%).

Invoice, Contract, Certificate, and Receipt starter schemas are returned by GET /templates.
