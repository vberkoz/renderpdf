Reusable assets and batch work

Batch rendering

POST/batches

Submit up to 99 PDFs in one job. A durable DynamoDB outbox dispatches each item to SQS; retries are at-least-once, while conditional worker claims prevent duplicate PDFs. Completed documents can be downloaded as a single merged PDF or a ZIP archive.

Submitting a batch job

{
  "version": "1",
  "source": { "type": "stored", "id": "src_01h8q..." },
  "items": [
    { "data": { "customer": { "name": "Ada" } } },
    { "data": { "customer": { "name": "Grace" } } }
  ],
  "options": {
    "webhookUrl": "https://example.com/hooks/render",
    "webhookSecret": "secret_key_123",
    "mergeOutput": true
  }
}
options.mergeOutputbooleanoptional

When set to true, RenderPDF automatically merges all completed item PDFs into a single continuous PDF document upon download, in addition to standard ZIP packaging.

GET /batchesAPI key

List all batch jobs owned by the authenticated account, sorted newest first (returns {"jobs": [...]}).

GET /batches/{id}API key

Read job state (queued|running|completed|completed_with_errors|cancelled|failed), totals, progress counts, and timestamps.

GET /batches/{id}/itemsAPI key

List item status and individual output file IDs.

POST /batches/{id}/cancelAPI key

Cancel pending items; active work completes safely.

Downloading batch results

GET /batches/{id}/downloadAPI key

Obtain a 15-minute signed S3 download URL for the completed batch output. Supports the format query parameter:

  • ?format=pdf: Materializes and downloads all completed items as a single unified, concatenated PDF document.
  • ?format=zip: Packages all individual PDFs into a ZIP archive.
  • (Omitted): Automatically selects pdf if the batch was submitted with mergeOutput: true, or zip otherwise.
Response format: {"fileId": "...", "url": "https://...", "format": "pdf|zip"}.

A job-level webhook emits one terminal batch.completed or batch.failed event. Permanently failing worker items are reconciled through the batch dead-letter queue.
