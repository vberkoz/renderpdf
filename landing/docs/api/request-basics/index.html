Request basics

All API routes are relative to https://renderpdf.vberkoz.com/api/v1 and exchange JSON unless the route explicitly returns a presigned upload URL.

Content-Type: application/jsonRequired for requests with a JSON body.
Authorization: Bearer <key>Required for production render, upload, template, and webhook requests.
Accept: application/jsonOptional; JSON is returned for successful and error responses.
i

Keep API keys on a trusted server. Browser code should call your backend rather than embed a production key.
