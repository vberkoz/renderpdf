Multi-document processing

Merge PDFs

POST/merge

Concatenate between 2 and 100 PDFs into a single unified document with continuous page numbering, watermarks, encryption, compliance metadata, and digital signatures in a single API call.

Endpoint details

You can call either POST /api/v1/merge or the alias POST /api/v1/pdf/merge with standard Bearer API key authentication. Each successful merge reserves one monthly quota unit.

Request parameters

versionstringoptional

Contract version. Defaults to "1".

filesarray of stringsoptional

Shorthand list of owned fileId strings or public http:// / https:// URLs pointing to PDF documents.

itemsarray of objectsoptional

Explicit list of items to merge. Each item object must specify exactly one of: fileId (owned file ID), url (public HTTP/HTTPS PDF URL), or data (base64-encoded PDF string).

optionsobjectoptional

Unified document post-processing options applied to the entire merged output:

  • pageNumbers: Re-stamp continuous page numbering across all concatenated pages (e.g. format: "Page {page} of {total}", position: "bottom-center").
  • watermark: Stamp a diagonal or rotated watermark across all merged pages (e.g. text: "CONFIDENTIAL", opacity: 0.15).
  • password, ownerPassword, permissions: Apply AES-256 password protection and restrict printing or copying.
  • compliance: Embed Factur-X / ZUGFeRD XML invoice and output an ISO PDF/A-3b compliant document.
  • signing: Cryptographically sign the final merged PDF with an X.509 certificate or AWS KMS.

labelstringoptional

Customer tracking label (up to 120 characters) displayed in dashboard logs and analytics.

webhookUrlstringoptional

Public HTTPS URL to receive an asynchronous pdf.completed webhook delivery with HMAC SHA-256 signature.

webhookSecretstringoptional

Secret key used to compute the HMAC signature in the X-RenderPDF-Signature header.

Limits

Input documents2 to 100
Total input payload50 MB
Fetch timeout15 seconds

Request example

cURL · Merge documents with page numbers & watermark
curl -X POST https://renderpdf.vberkoz.com/api/v1/merge \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version": "1",
    "files": [
      "file_01h8q7m9a1...",
      "https://example.com/legal-terms.pdf"
    ],
    "options": {
      "pageNumbers": {
        "format": "Page {page} of {total}",
        "position": "bottom-center",
        "fontSize": 9
      },
      "watermark": {
        "text": "CONFIDENTIAL",
        "diagonal": true,
        "opacity": 0.12
      }
    },
    "label": "Annual Report & Terms 2026"
  }'

Response

Returns 200 OK with the newly generated merged PDF metadata and a 15-minute signed download URL:

{
  "requestId": "4e292025-a13f-4e02-8a9c-0c4c47b59e31",
  "fileId": "file_01h8q7m...",
  "url": "https://renderpdf-storage.s3.amazonaws.com/files/.../uuid.pdf?X-Amz-Signature=...",
  "size": 98392,
  "pageCount": 14
}
