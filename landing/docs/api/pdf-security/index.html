Document password & security permissions

POST/render

Protect sensitive and confidential PDFs with industry-standard AES-256 encryption. Adding options.password prevents unauthorized access to vital enterprise records, such as financial statements, legal contracts, and payroll slips. You can also designate an ownerPassword for administrative rights and set permissions to restrict user rights.

passwordstringoptional

User password required to open and decrypt the document (up to 128 characters). Vital for safeguarding confidential financial statements, client contracts, and employee payroll slips.

ownerPasswordstringoptional

Owner password required to modify document permissions or remove protection (up to 128 characters). Defaults to password if omitted.

permissionsstringoptional

Permissions granted to users who open the PDF: all (default; full printing, copying, and modification rights), print (allows high-resolution printing only; prevents content extraction and modification), or none (view-only; prevents printing, copying, and modification).

cURL · Password-protected contract or payroll slip
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version": "1",
    "source": { "type": "html", "content": "<main><h1>Confidential Payroll Statement</h1><p>Employee: {{employee.name}}</p><p>Net Pay: {{payroll.netPay}}</p></main>" },
    "data": { "employee": { "name": "Jane Doe" }, "payroll": { "netPay": "$5,420.00" } },
    "options": {
      "format": "A4",
      "margin": "18mm",
      "password": "JanePayroll2026!",
      "ownerPassword": "FinanceMasterKey999!",
      "permissions": "print"
    }
  }'

Security options are configured under options in Document JSON or Render requests.
