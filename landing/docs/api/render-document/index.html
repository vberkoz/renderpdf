Render inputs

Render an HTML/CSS JSON document

POST/render

Send HTML structure, CSS, dynamic values, vector barcodes, and post-processing options separately. The authenticated endpoint validates the versioned contract, escapes bound values, builds a complete HTML document, and returns the standard PDF response.

Document contract fields

versionstringrequired

Contract version. Must be "1".

htmlstringrequired unless source is supplied

A non-empty HTML fragment containing optional {{path.to.value}} bindings and barcode tags.

sourceobjectoptional

Mutually exclusive with html. The Markdown shape is { type: "markdown", content: "..." }; it is converted to HTML with raw HTML disabled.

cssstringoptional

Document CSS supported by headless Chrome, subject to the safety restrictions below.

dataobjectrequired

Nested values for every binding. Missing values, unused leaves, and malformed bindings return 422; inserted values are HTML-escaped.

Layout, security & watermarking options (`options`)

formatstring

Paper format: A4 (default), Letter, or Legal.

marginstring

Margin in mm (0–50mm) or in (0–2in). Defaults: 18mm.

headerTemplate / footerTemplatestring

HTML templates for headers and footers (up to 64 KiB). Toggled with displayHeaderFooter: true.

pageNumbersobject

Post-render vector page numbering stamped via pdfcpu:

  • format: Template string with {page} and optional {total} (default: "Page {page} of {total}").
  • position: bottom-center, bottom-right, bottom-left, top-center, top-right, top-left.
  • startPage: First physical page to receive page numbers (1-indexed).
  • startNumber: Number to assign to startPage (defaults to 1).
  • excludeCover: Suppress numbering on cover page and adjust total count (default: false).
  • fontSize: Font size in points (1–72, default: 9).
  • color: 3 RGB floats (e.g. "0.4 0.4 0.4") or hex code.

watermarkobject

Diagonal or rotated vector watermark stamped across document pages:

  • text: Watermark string (e.g. "CONFIDENTIAL").
  • diagonal: Corner-to-corner diagonal (default: true).
  • rotation: Custom angle from -360 to 360 degrees. Overrides diagonal.
  • opacity: Float between 0.0 and 1.0 (default: 0.15).
  • color: RGB floats or hex color (e.g. "#dc2626").
  • fontSize: Font size in points (default: 54).
  • font: Helvetica, Times-Roman, or Courier.
  • position: center, top-center, top-left, top-right, bottom-center, bottom-left, bottom-right.
  • pages: "all", "odd", "even", "1", or "2-".

waitForobject

Smart wait triggers evaluated before printing:

  • selector: CSS selector to await until visible (e.g. "#chart svg").
  • networkIdle: "networkidle0" or "networkidle2".
  • timeoutMs: Milliseconds timeout (default: 5000).
  • fonts: Wait for web fonts before rendering (default: true).

password, ownerPassword, permissions

AES-256 PDF encryption. See Security & Passwords.

redaction

AST-level PII sanitization. See PII Redaction.

signing

Cryptographic digital signatures. See Digital Signatures.

compliance

Factur-X & PDF/A archival compliance. See Compliance & Factur-X.

Vector barcodes & QR codes in HTML

Embed resolution-independent vector barcodes and QR codes directly in your HTML content without loading client-side JavaScript libraries:

  • <qrcode value="https://pay.acme.com/1042" size="140" level="H" color="#000" background="#fff" />
  • <barcode type="code128" value="INV-2026" width="220" height="60" text="true" />
  • <div data-qrcode="https://example.com" data-qr-size="120px"></div>
  • <div data-barcode="PKG-9944" data-barcode-type="code128"></div>

Supported types: code128, code39, ean13, ean8, 2of5, datamatrix, pdf417, qr.

cURL example

cURL · Document JSON with watermark and barcode
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version": "1",
    "source": {
      "type": "html",
      "content": "<main><h1>{{report.title}}</h1><p>Customer: {{customer.name}}</p><barcode type=\"code128\" value=\"RPT-2026\" width=\"200\" height=\"50\" text=\"true\" /></main>"
    },
    "css": "body { font-family: Arial, sans-serif; } h1 { color: #123456; }",
    "data": {
      "report": { "title": "Monthly report" },
      "customer": { "name": "Ada & Sons" }
    },
    "options": {
      "format": "A4",
      "margin": "18mm",
      "pageNumbers": {
        "format": "Page {page} of {total}",
        "position": "bottom-center"
      },
      "watermark": {
        "text": "CONFIDENTIAL",
        "diagonal": true,
        "opacity": 0.1
      }
    }
  }'

CSS, limits, and security

Page size and margin are generated from options; @page in HTML or CSS is rejected. CSS @import, url(), unsafe legacy expressions, scripts, event-handler attributes, iframe, embed, object, applet, local files, and local or remote assets are rejected. JavaScript is disabled. Normal http, https, mailto, and #anchor links remain allowed.

Request / final input1 MiB
HTML / CSS768 / 128 KiB
Data256 KiB / 10 levels

Optional webhookUrl and webhookSecret fields use the same signed pdf.completed delivery flow as other authenticated render endpoints.
