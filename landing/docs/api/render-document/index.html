Render inputs

Render an HTML/CSS JSON document

POST/render

Send HTML structure, CSS, and dynamic values separately. The authenticated endpoint validates the versioned contract, escapes bound values, builds a complete HTML document, and returns the standard PDF response.

versionstringrequired

Contract version. The only supported value is "1".

htmlstringrequired unless source is supplied

A non-empty HTML fragment containing optional {{path.to.value}} bindings.

sourceobjectoptional

Mutually exclusive with html. The Markdown shape is { type: "markdown", content: "..." }; it is converted to HTML with raw HTML disabled.

cssstringoptional

Document CSS supported by headless Chrome, subject to the restrictions below.

dataobjectrequired

Nested values for every binding. Missing values, unused leaves, and malformed bindings return 422; inserted values are HTML-escaped.

optionsobjectoptional

Layout and document security settings. format may be A4, Letter, or Legal. margin accepts 0–50mm or 0–2in (defaults: A4 and 18mm). headerTemplate and footerTemplate accept HTML up to 64 KiB; displayHeaderFooter toggles headers and footers. password and ownerPassword set AES-256 encryption; permissions restricts user rights (all, print, or none). See Document password & security permissions below.

cURL
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "version":"1",
    "source":{"type":"html","content":"<main><h1>{{report.title}}</h1><p>{{customer.name}}</p></main>"},
    "css":"body { font-family: Arial, sans-serif; } h1 { color: #123456; }",
    "data":{"report":{"title":"Monthly report"},"customer":{"name":"Ada & Sons"}},
    "options":{"format":"A4","margin":"18mm"}
  }'

CSS, limits, and security

Page size and margin are generated from options; @page in HTML or CSS is rejected. CSS @import, url(), unsafe legacy expressions, scripts, event-handler attributes, iframe, embed, object, applet, local files, and local or remote assets are rejected. JavaScript is disabled. Normal http, https, mailto, and #anchor links remain allowed.

Request / final input1 MiB
HTML / CSS768 / 128 KiB
Data256 KiB / 10 levels

Optional webhookUrl and webhookSecret fields use the same signed pdf.completed delivery flow as other authenticated render endpoints. See Document password & security permissions for AES-256 encryption.
