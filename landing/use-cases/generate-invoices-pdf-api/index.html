How It Works: 3 Steps to Automated Invoicing

Integrate automated invoice generation into your SaaS billing workflow in minutes.

1

Define Structure & Data Bindings

Use standard HTML and CSS for layout. Mark dynamic values like customer names, amounts, and item tables with double-brace placeholders such as {{invoice.number}} and {{customer.name}}. All bindings are automatically HTML-escaped for security.

2

Send Render Request with Separated JSON

Submit your template and structured invoice values in a single clean JSON payload. RenderPDF compiles the document and renders it using headless Chromium in under two seconds.

POST /api/v1/render — Invoice Render Example 
curl -X POST https://renderpdf.vberkoz.com/api/v1/render \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "version": "1",
    "source": {
      "type": "html",
      "content": "<header><h1>Invoice {{invoice.number}}</h1><p>Bill To: {{customer.name}}</p></header><table><tr><th>Description</th><th>Total</th></tr><tr><td>{{item.title}}</td><td>{{item.amount}}</td></tr></table>"
    },
    "css": "body { font-family: sans-serif; margin: 0; } table { width: 100%; border-collapse: collapse; } th, td { padding: 10px; border-bottom: 1px solid #ddd; }",
    "data": {
      "invoice": { "number": "INV-2026-089" },
      "customer": { "name": "Acme Global Corp" },
      "item": { "title": "Platform Subscription (Annual)", "amount": "$1,200.00" }
    },
    "options": {
      "format": "A4",
      "margin": "18mm",
      "displayHeaderFooter": true,
      "footerTemplate": "<div style=\"font-size: 9px; width: 100%; text-align: center; color: #888;\">Page <span class=\"pageNumber\"></span> of <span class=\"totalPages\"></span></div>"
    }
  }'
3

Download or Deliver via Webhook

RenderPDF saves the generated PDF to encrypted Amazon S3 storage and returns a 15-minute presigned download URL. For asynchronous billing batches, provide a webhookUrl to receive a signed callback when the invoice is ready.

Frequently Asked Questions

Common questions about generating invoices with RenderPDF.

How do I prevent invoice table rows from splitting across pages?

In your CSS, add tr { break-inside: avoid; page-break-inside: avoid; } to your table styling. This forces Chromium to keep each line item row together. If a row does not fit at the bottom of page one, it cleanly wraps to page two.

Can I password-protect invoices sent to customers?

Yes. Simply add "password": "customer-password" inside your options object. RenderPDF applies AES-256 encryption. You can also specify ownerPassword and set permissions: "print" to allow printing while prohibiting text extraction.

How do dynamic page numbers ("Page 1 of 3") work?

Enable displayHeaderFooter: true in your render options and supply an HTML footerTemplate. Chromium automatically populates elements with class names pageNumber and totalPages at render time without needing server-side page calculation.

Can I store an invoice template once and only submit variables?

Yes. RenderPDF supports durable template storage via POST /api/v1/templates. Once uploaded, you can render invoices with {"source": {"type": "template", "templateId": "...", "variables": {...}}}. This keeps request payloads lightweight and ensures template version control.
