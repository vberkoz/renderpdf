How to Convert HTML to PDF in Python (Fast & Modern)

Struggling with WeasyPrint's system C-dependencies in Docker, deprecated wkhtmltopdf vulnerabilities, or heavyweight Playwright containers? RenderPDF lets Python engineers convert HTML to PDF with a simple requests call.

No Cairo or Pango C-Libs

WeasyPrint requires libcairo2, libpango-1.0, and libgdk-pixbuf. In minimal Docker images, maintaining these native packages causes bloat and compilation failures.

Goodbye Abandoned wkhtmltopdf

wkhtmltopdf is officially archived and relies on an unpatched 2012 WebKit fork. It lacks modern CSS Grid, Flexbox, and modern web fonts, and introduces serious SSRF risks.

Instant Cloud Scale

Running headless Chrome via Pyppeteer or Playwright consumes 500MB+ RAM per process. RenderPDF offloads browser rendering to serverless Lambda workers automatically.

Step-by-Step: Converting HTML to PDF in Python

A complete walkthrough using Python and the standard requests library.

1

Basic Conversion with Requests (Zero System Libs)

Install requests via pip install requests and generate your first PDF in less than 20 lines of code:

render_pdf.py 
import os
import requests

def html_to_pdf(html_content: str, output_filename: str):
    api_key = os.environ["RENDERPDF_API_KEY"]
    
    payload = {
        "version": "1",
        "source": {
            "type": "html",
            "content": html_content
        },
        "options": {
            "format": "A4",
            "margin": "18mm"
        }
    }
    
    response = requests.post(
        "https://renderpdf.vberkoz.com/api/v1/render",
        headers={
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        },
        json=payload,
        timeout=15
    )
    response.raise_for_status()
    data = response.json()
    
    # Download the rendered PDF from the secure presigned S3 URL
    pdf_response = requests.get(data["url"], stream=True, timeout=15)
    pdf_response.raise_for_status()
    
    with open(output_filename, "wb") as f:
        for chunk in pdf_response.iter_content(chunk_size=8192):
            f.write(chunk)
            
    print(f"PDF saved to {output_filename} ({data['size']} bytes)")

# Example usage
html_to_pdf("<h1>Invoice #4029</h1><p>Client: Wayne Enterprises</p>", "invoice.pdf")

Structured Data Interpolation (No Jinja2 Needed)

FastAPI / Django Streaming Response

Here is how to serve the generated PDF directly in a FastAPI endpoint without writing to local disk:

main.py (FastAPI) 
from fastapi import FastAPI, HTTPException
from fastapi.responses import StreamingResponse
import httpx
import os

app = FastAPI()
API_KEY = os.environ.get("RENDERPDF_API_KEY")

@app.post("/download-report")
async def download_report(title: str):
    async with httpx.AsyncClient() as client:
        render_res = await client.post(
            "https://renderpdf.vberkoz.com/api/v1/render",
            headers={"Authorization": f"Bearer {API_KEY}"},
            json={
                "version": "1",
                "source": {"type": "html", "content": f"<h1>{title}</h1>"},
                "options": {"format": "A4"}
            }
        )
        if render_res.status_code != 200:
            raise HTTPException(status_code=500, detail="Render failed")
            
        pdf_url = render_res.json()["url"]
        pdf_stream = await client.get(pdf_url)
        
        return StreamingResponse(
            pdf_stream.aiter_bytes(),
            media_type="application/pdf",
            headers={"Content-Disposition": "attachment; filename=report.pdf"}
        )

Frequently Asked Questions

Common questions about generating PDFs from Python applications.

Does this require installing Cairo, Pango, or GObject in Docker?

No! Because RenderPDF performs all headless browser rendering on dedicated cloud infrastructure, your Python Docker container needs zero system C-libraries. You can use ultra-slim Python Alpine or Debian-slim base images without apt-get dependencies.

Can I encrypt PDFs with passwords in Python?

Yes. Add "password": "secret" and optionally "permissions": "print" to the options dict. RenderPDF applies native AES-256 encryption before returning the signed download URL.

How do I test RenderPDF in Python without an API key?

Send a POST request to https://renderpdf.vberkoz.com/api/v1/trial/render with {"html": "<h1>Test</h1>"}. No headers or authorization are required. Each IP receives 3 free trial renders daily.

How can I run batch PDF exports with Celery?

You can submit asynchronous batch jobs with up to 99 items per request using POST /api/v1/batches and configure a webhookUrl. RenderPDF will notify your Celery or Django backend when the batch ZIP archive is ready.
