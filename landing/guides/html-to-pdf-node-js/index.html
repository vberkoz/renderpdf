How to Convert HTML to PDF in Node.js (Without Puppeteer)

Self-hosting Puppeteer or Playwright in Node.js leads to heavy 300MB+ container builds, zombie browser processes, and memory crashes. RenderPDF lets you render production PDFs via standard native fetch with zero npm dependencies.

Puppeteer installs a 300MB+ headless Chromium binary that regularly blows past AWS Lambda and serverless bundle limits. RenderPDF requires only a lightweight HTTP request.

Step-by-Step: Converting HTML to PDF in Node.js

Follow this tutorial to integrate PDF generation into your Node.js or TypeScript application.

1

Minimal Example with Native Fetch (Zero Dependencies)

Node.js 18 and newer include native fetch globally. Here is a complete script to generate a PDF and write it to disk:

generate-pdf.mjs 
import fs from 'node:fs/promises';

async function generatePDF() {
  const response = await fetch('https://renderpdf.vberkoz.com/api/v1/render', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${process.env.RENDERPDF_API_KEY}`
    },
    body: JSON.stringify({
      version: '1',
      source: {
        type: 'html',
        content: '<main><h1>Invoice #1042</h1><p>Amount Due: $450.00</p></main>'
      },
      options: {
        format: 'A4',
        margin: '15mm'
      }
    })
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(`PDF generation failed: ${error.message || response.statusText}`);
  }

  const { url } = await response.json();

  // Download the generated PDF from the secure presigned S3 URL
  const pdfResponse = await fetch(url);
  const buffer = Buffer.from(await pdfResponse.arrayBuffer());
  await fs.writeFile('invoice.pdf', buffer);
  console.log('PDF saved to invoice.pdf successfully!');
}

generatePDF().catch(console.error);

TypeScript Definitions

Drop these type definitions into your TypeScript codebase for complete autocomplete and type safety:

types/renderpdf.ts 
export interface RenderRequest {
  version: '1';
  source:
    | { type: 'html'; content: string }
    | { type: 'markdown'; content: string }
    | { type: 'template'; templateId: string; variables?: Record<string, unknown> }
    | { type: 'url'; url: string };
  css?: string;
  data?: Record<string, unknown>;
  options?: {
    format?: 'A4' | 'Letter' | 'Legal';
    margin?: string;
    landscape?: boolean;
    displayHeaderFooter?: boolean;
    headerTemplate?: string;
    footerTemplate?: string;
    password?: string;
  };
  webhookUrl?: string;
  webhookSecret?: string;
}

export interface RenderResponse {

  url: string;
  size: number;

Frequently Asked Questions

Everything you need to know about using RenderPDF in Node.js and TypeScript.

Can I run this on Vercel, Netlify, or Cloudflare Workers?

Yes. Because RenderPDF is an external REST API, your serverless functions do not need to bundle Chromium or maintain a headless browser instance. It works smoothly on Vercel Serverless/Edge Functions, Netlify Functions, Cloudflare Workers, and AWS Lambda.

How do I test without an API key in Node.js?

Send a POST request to https://renderpdf.vberkoz.com/api/v1/trial/render with {"html": "<h1>Hello World</h1>"}. You can perform 3 trial renders per IP address every day without any headers or authentication.

How does RenderPDF handle external CSS fonts and images?

You can reference Google Fonts via <link> or standard @import, or inline images as Base64 data URIs. For bundled local assets (images, fonts, stylesheets, scripts), use RenderPDF's ZIP package upload endpoint (POST /api/v1/files/upload).

How long does the returned download URL remain valid?

The returned S3 download URL is presigned and cryptographically signed by AWS. It expires after 15 minutes. Once downloaded, you can save the PDF to disk, upload it to your own storage bucket, or stream it to your end user.
