4. Usage Limits and Quotas

To ensure system stability, fair resource sharing, and reliable performance across all customers, RenderPDF enforces specific technical and account-level limits:

  • Free tier: 25 PDF renders per calendar month.
  • Starter tier: 5,000 PDF renders per monthly billing period.
  • Professional tier: 20,000 PDF renders per monthly billing period.
  • Trial endpoint: 3 renders per UTC day per source IP address hash without an API key.
  • Payload constraints: Maximum 1 MiB request JSON, 768 KiB HTML body, 128 KiB CSS, 256 KiB dynamic variable data, 10 data nesting levels, and 1 MiB final rendered input. Uploaded ZIP packages are limited to 25 MB compressed, 50 MB uncompressed, and 500 files.
  • Template constraints: Up to 100 stored customer templates per account, with a maximum of 1 MiB per template.
